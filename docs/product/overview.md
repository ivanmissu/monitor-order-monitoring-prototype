# 产品概览

> 面向产品、运营与新加入的研发：Monitor 是什么、给谁用、解决什么问题、边界在哪里。
> 想直接看每个页面能做什么，见[视图详解](./views.md)。

---

## 一句话定位

Monitor 是一个**旁路式订单业务监控平台**：它只消费业务系统发出的领域事件，
把「订单在各业务线里发生了什么」聚合成可观测的指标、看板与告警，
**不回写任何业务存储，也不参与业务链路**。业务系统挂了 Monitor 不会跟着挂，
Monitor 挂了也不会影响下单、派单、支付。

覆盖业务线：司机端、转单端、顺风车、代驾、接送机，以及跨线的「全平台总览」。

---

## 解决什么问题

传统做法是「出了问题再去查日志/数据库」，Monitor 要解决的是这几类日常痛点：

| 场景 | 没有 Monitor 时 | 有 Monitor 后 |
| --- | --- | --- |
| 凌晨某城市订单量突然掉一半 | 等客诉上来才发现，排查要跨好几个系统捞日志 | 值班哨红绿灯 + 告警直接指出是哪条业务线、哪个城市、卡在哪一步 |
| 客服接到「我的订单为什么被取消」 | 找研发帮忙查库，来回几十分钟 | 客服工作台输入订单号，完整事件时间线秒出 |
| 运营问「这周履约率为什么降了」 | 各人用各自的 SQL 口径，结论对不上 | 指标库是唯一口径真源，所有看板都从同一份定义派生 |
| 监控系统自己断流了 | 看板一片绿，误以为业务正常 | 元监控专门盯管道健康，断流时打「失明」横幅而不是装作没事 |

## 三条产品原则

这三条不只是技术选择，它们直接决定了用户看到的数字可不可信。

### 1. 比率不落库

存储层只保留**可加性原子指标**（分子、分母各自的计数），
所有比率（履约率、取消率、失败率）都在**查询时由分子除以分母现算**。

为什么重要：比率不可加，「各城市取消率的平均」不等于「整体取消率」。
先落比率再聚合，数字一定是错的。另一个好处是口径调整不需要回刷历史数据。

### 2. 口径不硬编码

指标定义、漏斗步骤、告警阈值统一来自**指标字典**，不写死在代码里。
运营改一次口径，所有看板同步生效，不需要发版。指标库视图就是这份字典的界面。

### 3. 权限即数据源

不同角色的 Token 绑定**不同的数据库账号与可访问范围**，不是在应用层做过滤。
客服账号从数据库层面就查不到聚合大盘，越权请求直接 `403`。
这样也顺带做了资源隔离：客服的明细慢查询不会占满大盘查询的内存配额。

## 数据怎么来的

```text
业务系统（下单/派单/支付…）
   │  状态跃迁时，在同一事务提交后发出领域事件
   ▼
Monitor SDK ──→ Kafka ──→ 校验/去重 ──→ ClickHouse ODS 明细层
                                            │ 物化视图自动上卷
                                            ▼
                                   1m / 5m / 1h / 1d 聚合层
                                            │
                                     看板查询 · 告警求值
```

两条硬约束：

- **事件必须是「发生时刻的快照」**：城市、座位类型、金额等维度要在事件里带上，
  不能等查询时回连业务库补 —— 否则历史数据会随业务库变化而漂移。
- **至少一次投递，消费端去重**：靠 `event_id` 幂等键，重复上报不会重复计数。

完整字段契约见[事件契约](../tech/api-reference.md#16-事件契约生产侧)。

## 当前状态与边界

这是一个**原型（prototype）**，架构与数据链路完整可跑，但以下几项在接真实业务前必须处理：

| 项目 | 现状 | 说明 |
| --- | --- | --- |
| 鉴权 | ⚠️ 演示态静态 Token | `dash-token` 等为**硬编码明文**，任何人拿到即可读全量数据。生产须接 SSO 换短时效用户态 Token |
| 告警通知 | 仅站内 + SSE 推送 | 未接企业微信/钉钉/电话外呼 |
| 后端水平扩展 | 单副本 | 定时任务无分布式选主，详见 [K8s 部署手册 §9](../ops/k8s-deployment.md#9-扩容与高可用) |
| 数据规模 | 按 ≈250 万事件/天设计 | 1 分片 × 2 副本，ODS 压缩后 <100MB/天 |

前端在**服务端不可达时会自动回退到内置演示数据**，页面右上角徽标会显示「演示数据」而非「实时接口」。
这个设计方便离线演示，但也意味着**页面能打开 ≠ 后端正常**，排查时请以徽标为准。
